# Feedforward Neural Network

A collection of Jupyter notebooks exploring the fundamentals of Artificial Neural Networks (ANNs) — from a single perceptron to full feedforward networks applied to classification and regression problems.

## 📌 Overview

This repository is a hands-on, from-basics-to-application walkthrough of feedforward neural networks, built for learning and practicing core deep learning concepts such as neurons, weights, activation functions, and backpropagation.

## 📂 Contents

| File | Description |
|------|-------------|
| `perceptron_neuron.ipynb` | Implements a single perceptron/neuron to understand the basic building block of neural networks. |
| `ANN_Practise.ipynb` | General practice notebook covering core ANN concepts and implementation. |
| `ANN_for_classification.ipynb` | Builds a feedforward ANN to classify data from the Date Fruit dataset (`Date_fruit.csv`). |
| `ANN_regression.ipynb` | Builds a feedforward ANN to solve a regression problem using power plant data (`powerplat_data.csv`). |
| `Date_fruit.csv` | Dataset used for the classification notebook. |
| `powerplat_data.csv` | Dataset used for the regression notebook. |

## 🛠️ Tech Stack

- Python
- Jupyter Notebook
- PyTorch
- NumPy, Pandas, Scikit-learn (for data handling, preprocessing, and evaluation)

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/kshitiznagar/Feedforward-neural-network.git
   cd Feedforward-neural-network
   ```
2. Install the required dependencies (create a virtual environment if you like)
   ```bash
   pip install numpy pandas scikit-learn torch matplotlib jupyter
   ```
3. Launch Jupyter Notebook and open any file to explore
   ```bash
   jupyter notebook
   ```

## 🎯 Learning Goals

- Understand how a single perceptron/neuron processes inputs
- Build feedforward neural networks from the ground up
- Apply ANNs to a real-world classification task
- Apply ANNs to a real-world regression task
- Get comfortable with the end-to-end ML workflow: data loading, preprocessing, model building, training, and evaluation
